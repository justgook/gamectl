Welcome to the Design System

This is a lightweight design system showcase built with plain HTML and CSS. It demonstrates all design tokens and components using the DTCG (Design Tokens Community Group) standard format. No heavy JavaScript frameworks required - just simple, clean HTML that showcases the design system.

What's Included

Design Tokens

Browse all global and semantic tokens including colors, typography, spacing, borders, shadows, and more. All tokens follow the DTCG standard and are properly typed.

Components

Explore interactive components like buttons, panels, select inputs, lists, and file trees. Each component demonstrates proper usage of design tokens and includes hover states.

About DTCG Standard

The Design Tokens Community Group (DTCG) format is a W3C standard for defining design tokens. Key features include:

  • ✓ Proper type declarations with $type
  • ✓ Clean reference syntax without .value suffix
  • ✓ Composite types for shadows and typography
  • ✓ Clear separation of global, semantic, and component tokens
  • ✓ Build-time transformation to CSS custom properties
