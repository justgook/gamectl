# Automap Fixture Workflow

Automap golden fixtures live in `plugins/automap/testdata/<case>/`.

Each case contains:

- `input.json` - native input tilemap
- `rules.json` - native automap rule map
- `output.json` - golden result generated by Tiled

## Regenerate Fixtures

From `plugins/automap/` run:

```sh
make generate-fixtures
```

To regenerate selected cases only:

```sh
make generate-fixtures CASES="new_rules rules"
```

This workflow:

- installs a repo-local Tiled extension
- writes temporary `.tmj`, `.tsj`, and `rules.txt` files into `build/automap-fixtures/`
- launches a new Tiled instance
- asks Tiled to automap each fixture case
- writes fresh `output.json` files back into `plugins/automap/testdata/`

## Manual UI Path

If you want to inspect or rerun from the UI:

```sh
make open-tiled
```

Then use `Map -> Generate Automap Fixtures` inside Tiled.

## Adding New Cases

1. Create `plugins/automap/testdata/<case>/input.json`
2. Create `plugins/automap/testdata/<case>/rules.json`
3. Add the case name to `plugins/automap/testdata/cases.json`
4. Run `make generate-fixtures CASES="<case>"`
5. Run `go test ./plugins/automap`
