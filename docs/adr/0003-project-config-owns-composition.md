# Project config owns long-term GAMS composition

During development, built-in base plugins such as `gams:fs` may be hardcoded into host bootstrap so the runtime can move quickly. Long term, GAMS will be a small orchestration/plugin-management runtime and each Project Config will define the Project Units that make that Project its own tool: theme, plugins, views, UI Services, and their configuration, runnable by different hosts such as browser and CLI. Presets belong to view configuration, scripts belong to UI Service key/action configuration, and Project Units should ship JSON Schemas for validating their Project Config sections.
