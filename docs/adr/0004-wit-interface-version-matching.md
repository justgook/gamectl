# Match WIT interfaces by package/interface and compatible major/minor versions

GAMS runtime dependency resolution matches WIT providers to imports by normalising full interface names from `namespace:package/interface@major.minor.patch` to the compatibility identity `package/interface@major.minor.patch`: namespace is provenance, not compatibility identity. Duplicate providers are rejected by interface family `package/interface@major`; a provider satisfies an import when package and interface match, major matches, provider minor is greater than or equal to import minor, and patch is ignored. Frontend invocation targets must remain namespace-less and version-less (`package/interface::function`), while Wasmtime wiring still preserves/aliases the exact full import name required by the consuming component.

This is surprising enough to record because future maintainers may otherwise treat namespace as part of compatibility or force frontend callers to include versions. The current implementation confirms this in `cmd/app/src-tauri/src/runtime/mod.rs`: `parse_interface_id` discards namespace into `package`, `InterfaceId::family` uses package/interface/major, `version_satisfies` checks equal major and provider minor >= requested minor, and `parse_invocation_interface_id` rejects namespace/version in frontend invocation targets.
