# Idea Inbox

This directory is for ideas that are not yet requirements or decisions.

Use it when an idea needs to be captured, discussed, converted, or dismissed with a reason. Ideas here are source material only; they are not commitments to implement.

## Types

- `yoinking/` — competitive inspiration / strategic duplication / market-validated replication records.

## Idea lifecycle

1. **Captured** — the idea is recorded with source material and initial notes.
2. **Discussed** — ambiguity has been grilled down enough to understand the idea.
3. **Converted** — useful parts were moved into a PRD, ADR, or `CONTEXT.md`.
4. **Dismissed** — the idea will not be pursued, with the reason recorded.

## Definition of done for an idea

An idea is done when one of these is true:

- it links to the PRD/ADR/glossary entries that absorbed it; or
- it is marked dismissed with a clear reason.

Do not leave discussed ideas in an ambiguous state.
