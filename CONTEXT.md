# GAMS

GAMS is a plugin-driven CMS/toolkit for managing game assets, game data, and related workflows.

This repo now uses a multi-context domain model. Read `CONTEXT-MAP.md` first, then the context file relevant to the work:

- `docs/contexts/core-runtime/CONTEXT.md`
- `docs/contexts/project-composition/CONTEXT.md`
- `docs/contexts/documentation-system/CONTEXT.md`

Keep this root file as an overview only; context-specific vocabulary belongs in the files above.
