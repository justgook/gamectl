# PROTOTYPE — Freight Terminal Flat Baseline

## Question

Does the accepted Rifle Marine movement and combat vocabulary feel satisfying across the seven-beat flat Freight Terminal Encounter before route, Memory Imprint, contrasting-character, art, and campaign systems are added?

This is deliberately throwaway browser code beside the eventual game. It uses geometric placeholders and no private or licensed assets.

## Run

```sh
cd examples/demo/game
make prototype
```

Open <http://localhost:8813>.

## Controls

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Move | `A` / `D` | left stick / D-pad |
| Jump | `Space` | south face button |
| Slide | `Shift` or `S` | east face button |
| Aim and fire | arrow keys | right stick |
| Use terminal | `E` | west face button |
| Restart | `R` | — |
| Debug overlay | `F1` | — |

## Evidence to capture

- Does running reverse quickly without feeling frictionless?
- Are short and full jumps both useful?
- Are low and high projectile responses immediately readable?
- Is the slide deliberate without functioning as invulnerability?
- Is jumping over and reversing on the Shield Enforcer reliable?
- Does crane plus sentry create a decision rather than noise?
- Does the camera support advance and retreat without pulling aim?
- Can the successful pass stay near three to five minutes for a first-time player?

## Verdict

> **Needs evidence** — Playtest before preserving any values or implementation. Record findings in the GDD, then delete or absorb this prototype.
