# Yonking

A list of code, assets, and ideas to borrow or learn from later.

- [ ] **3D animations → 2D sprites** — Get the model and animation sources from the [Defold 3D Animations example](https://defold.com/examples/animation/3d_animations/), then render the animation set into sprites for use in a 2D game. The character comes from the [Quaternius Universal Animation Library](https://quaternius.itch.io/universal-animation-library).
- [ ] **Specular maps for dynamically lit pixel art** — Adapt the albedo + normal + hand-painted specular workflow shown in [this video](https://www.youtube.com/watch?v=EA_A8qhTh-8) so materials such as metal can glisten while wood or stone stays matte. Investigate packing grayscale specular data into an otherwise unused channel of the normal-map texture to avoid an extra texture; the video itself uses a separate specular map, so channel packing is our proposed adaptation.
- [ ] **Blender setup for pixel-art assets** — Try the workflow from [this Blender pixel-art tutorial](https://www.youtube.com/watch?v=PBIPJdEECWg): render at low resolution without anti-aliasing, use Standard color management and an orthographic camera, texture models from a fixed palette, animate at a low frame rate with constant interpolation, and batch-render directional sprites. Also investigate its Workbench normal-map rendering technique for producing matching maps for dynamic 2D lighting.
