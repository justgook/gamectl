🎬 Timeline Recording & Editing Demo

📹 Recording Animations

🎯 Quick Start: Use the timeline to record and edit animations for your game characters!

Method 1: Auto-Record Mode

  1. Switch to Timeline view using the dropdown above
  2. Click the 🔴 Record button to enable recording
  3. Switch to Skeleton view in another panel
  4. Manipulate bones - transformations are automatically captured
  5. Click 🔴 Record again to stop recording
  6. Return to Timeline and click ▶ Play to see your animation!

Method 2: Manual Keyframe Creation

  1. Right-click on any track in the timeline
  2. Select "Add Keyframe" from the context menu
  3. Enter keyframe values in the popup editor
  4. Keyframe appears at the current time position
  5. Repeat for multiple keyframes to create animation

✏️ Editing Keyframes

Basic Editing

  • Click on any keyframe to select it
  • Double-click to open the keyframe editor
  • Right-click for context menu with track options
  • Drag keyframes to move them in time
  • Ctrl+Click for multi-selection

Keyboard Shortcuts

  • Space - Play/Pause animation
  • Delete - Delete selected keyframes
  • Ctrl+C/V - Copy/Paste keyframes
  • Escape - Stop animation

🎯 Workflow Example

Creating a Simple Arm Wave Animation:
  1. Load the default timeline (should show 0.00s / 2.00s)
  2. Click 🔴 Record to start recording
  3. Move to time 0.0s
  4. In Skeleton view, rotate the arm bone up 45 degrees
  5. Move to time 1.0s
  6. Rotate the arm bone down -30 degrees
  7. Move to time 2.0s
  8. Rotate the arm bone back to 0 degrees
  9. Click 🔴 Record to stop recording
  10. Return to Timeline view
  11. Click ▶ Play to see your arm wave animation!

🎨 Visual Guide

Keyframe Shapes:

  • ○ Circle - Keyframe with easing (smooth transition)
  • ◇ Diamond - Linear keyframe (straight transition)
  • ● Filled - Selected keyframe

Recording Indicators:

  • 🔴 Red Record Button - Recording is active
  • Pulsing Border - Timeline is in record mode
