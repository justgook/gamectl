# GAMS app brand assets

These are the source vector assets for the Tauri application identity.

- `icon.svg` — primary app icon/logo source. This is the icon currently used to generate `build.nosync/app/icons/*` and `src/favicon.svg`, and should be the base for future design-system logo work.

Regenerate app icons from the primary source with:

```sh
make app-icons
```
